# 5JAD — منصة كورسات (تكملة المشروع)

نفس التصميم والمحتوى اللي كان في مشروع Bolt، لكن دلوقتي متوصّل بباك اند حقيقي:
Firebase Auth + Firestore (نفس مشروع `msmath-886cf`) وCloudinary لرفع الملفات.

## اللي اتعمل

- **تسجيل دخول / حساب جديد حقيقي**: بريد وكلمة سر، ودخول بجوجل، ونسيت كلمة السر —
  كل ده شغال فعليًا على Firebase Auth (مش شكل واجهة بس).
- **توجيه تلقائي حسب الدور**: بعد تسجيل الدخول، الطالب يروح للوحته والأدمن يروح للوحته،
  على حسب حقل `role` في مستند المستخدم في Firestore.
- **الكورسات والباقات ديناميكية**: بتتجاب لايف من `courses` و`plans` في Firestore،
  ولو الكولكشن فاضي بيظهر نفس المحتوى التجريبي الأصلي (عشان الموقع منظهرش فاضي).
- **الاشتراك والدفع الحقيقي**: الطالب يختار باقة، يرفع صورة إيصال الدفع (Vodafone
  Cash/InstaPay) على Cloudinary، وده بيعمل طلب في `paymentRequests`. حالة الاشتراك
  (لسه/تحت المراجعة/مفعّل) بتتحدّث لايف على حسب رد الأدمن.
- **لوحة الأدمن حقيقية**: إحصائيات لايف (عدد الطلاب، الاشتراكات الفعّالة، الطلبات
  المعلّقة، عدد الكورسات)، صفحة "Payment requests" فيها كل الطلبات مع زرار
  Approve/Reject بيحدّث اشتراك الطالب فورًا، وصفحة "Courses" فيها فورم بسيط لإضافة
  كورس جديد يتحفظ في Firestore.
- **الإشعارات**: بتتقرا لايف من كولكشن `notifications` (لسه محتاجة واجهة للأدمن
  عشان يبعتها — شايفة تفصيلة تحت).

## لسه واجهة بس (مش موصولة ببيانات حقيقية)

الحاجات دي اتسابت زي ما هي في التصميم الأصلي عشان الأولوية كانت للتسجيل/الاشتراك/
الكورسات، وبناء نظام امتحانات ودرجات حقيقي شغلانة كبيرة لوحدها:
- **صفحة الامتحانات (Exams)** — لسه شكل تجريبي، مفيش محرّك امتحانات حقيقي.
- **صفحة الدرجات (My grades)** — أرقام تجريبية ثابتة.
- **صفحة المواد (Materials)** — قائمة تجريبية، لسه مفيش رفع/عرض ملفات حقيقي من Cloudinary.
- **إرسال إشعارات من الأدمن** — الطالب بيقرا الإشعارات لو موجودة، بس لسه مفيش فورم
  للأدمن يبعت بيها إشعار جديد.

قولّي لو عايز أكمل أي حاجة من دول.

## قبل ما تشغّل المشروع

### 1. بيانات Firebase (مشروع msmath-886cf)
افتح `src/lib/firebase.ts` وحط بياناتك الحقيقية بدل الـ placeholders:
`apiKey`, `messagingSenderId`, `appId` (من Firebase Console → Project settings → Your apps → SDK config).

### 2. بيانات Cloudinary
افتح `src/lib/cloudinary.ts` وحط:
- `CLOUD_NAME`: اسم حسابك على cloudinary.com
- `UPLOAD_PRESET`: اعمل Upload preset من Settings → Upload، وخليه Unsigned

### 3. قواعد أمان Firestore
ارفع `firestore.rules` (الموجودة في جذر المشروع) على مشروعك في Firebase Console
(Firestore Database → Rules)، أو عن طريق Firebase CLI:
```bash
firebase deploy --only firestore:rules
```

### 4. أول حساب أدمن
مفيش واجهة لعمل أدمن من جوه الموقع (لأمان). بعد ما تعمل حساب عادي من صفحة "حساب
جديد"، روح Firestore Console → كولكشن `users` → مستند المستخدم ده، وغيّر حقل
`role` من `student` لـ `admin` يدويًا.
